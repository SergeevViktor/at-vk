# Homework №1

## Структура проекта (многомодульный Maven)

| Модуль | Назначение                                                                                                                     |
|---|--------------------------------------------------------------------------------------------------------------------------------|
| **`core-common`** | Модуль конфигурации. Содержит базовые настройки Spring Context, загрузку свойств (`@ConfigurationProperties`) и общие утилиты. |
| **`core-rest`** | Базовый слой для отправки REST-запросов. Содержит обёртку над Rest Assured (`Rest`) и интеграцию с Allure.                     |
| **`fakestoreapi`** | Модуль с бизнес-логикой тестирования. Содержит сервис `FakeStoreApiRestService`, тестовые данные, DTO и сами тесты.            |

## 🔌 Тестируемые эндпоинты FakeStoreAPI

### Пользователи (`/users`)

| Метод | Эндпоинт | Описание |
|---|---|---|
| `GET` | `/users` | Получить список всех пользователей |
| `POST` | `/users` | Добавить нового пользователя |
| `PUT` | `/users/{id}` | Обновить пользователя по ID |
| `DELETE` | `/users/{id}` | Удалить пользователя по ID |

### Аутентификация (`/auth`)

| Метод | Эндпоинт | Описание |
|---|---|---|
| `POST` | `/auth/login` | Аутентификация пользователя и получение JWT-токена |
